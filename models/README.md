# Modèles locaux

Ce dossier contient les poids entraînés utilisés par l'interface:

- `efficientnet_b0.pth`
- `resnet_50.pth`
- exports Raspberry Pi `*_rpi.pt`
- métadonnées `*_meta.json`

Les fichiers `.pth` et `.pt` sont ignorés par Git car ils sont lourds. Les métadonnées JSON restent versionnables.
